# Find Skills — Intelligent Skill Discovery & Recommender

Use this skill when you are unsure which installed skill best matches your current objective or workflow.

## Instructions

1. **Analyze Current Task:** Identify the core technical domain (frontend, backend, testing, security, planning, debugging, token optimization, or database).
2. **Scan Installed Skills:** Check `.agents/skills/` directory for applicable skills.
3. **Map Task to Pack:**
   - **Token Optimization:** `caveman`, `caveman-compress`, `cavecrew`
   - **Engineering Methodology:** `brainstorming`, `writing-plans`, `executing-plans`, `systematic-debugging`, `test-driven-development`
   - **UI/UX Design:** `ui-ux-pro-max`, `design-system`, `brand`, `banner-design`, `ui-styling`
   - **Code Quality:** `code-review-and-quality`, `qodo-get-rules`, `spec-driven-development`, `source-driven-development`
   - **Testing:** `playwright-skill`, `browser-testing-with-devtools`
   - **Security:** `scan-secrets`, `check-hmsl`, `install-hooks`, `security-and-hardening`
   - **Database:** `supabase`, `supabase-postgres-best-practices`
   - **DevOps & Shipping:** `ci-cd-and-automation`, `shipping-and-launch`, `git-workflow-and-versioning`
4. **Recommend:** Invoke or suggest the specific skill with its clear purpose and rationale.

# WorkSync engineering kit

A plan and tooling for building one company-wide progress-reporting and work-sync system (boards, items, views, automations, dashboards, forms, daily check-ins, offline field reporting), modeled on what monday.com and Trello do and designed fresh for this company. "WorkSync" is a working name.

| Start here | |
|---|---|
| `docs/architecture/MASTER_GUIDE.md` | The plan: users, build-vs-buy, rules, data model, reporting, automations, architecture, privacy, milestones W0-W7 |
| `docs/research/FEATURE_ANALYSIS.md` | What monday.com and Trello do (with sources) and what we take, change, or skip |
| `AGENTS.md` | Short rules every coding agent reads (copy to the repo root) |

## What is in the kit

| Path | What |
|---|---|
| `.agents/agents/` | 20 role files (generated by `node scripts/gen-agents.mjs`) |
| `.agents/skills/` | 15 skills: data model, permissions, authz tests, automations, offline sync, realtime, reporting, worker privacy, integrations, templates, threat model, audit, migrations, PR checklist, ADRs |
| `plugin/worksync/` + `.claude-plugin/marketplace.json` | Claude Code plugin: the agents and skills, 5 slash commands, 2 hooks |
| `scripts/authz-guard.mjs` | Authorization lint for the NestJS API (global guard, allow-listed public routes, guarded WebSocket handlers, DTO whitelist) |
| `scripts/*.test.mjs` | Tests for the lint and the hooks |
| `.github/` | CI, Dependabot, PR template |
| `.vscode/extensions.json`, `.mcp.json` | Recommended extensions; Context7 and Playwright MCP (versions pinned) |
| `docs/adr/ADR-000-template.md` | ADR template |

## Use it with Claude Code

```
/plugin marketplace add <path to this folder>
/plugin install worksync@worksync-local
```
Commands: `/ws-gate W0..W7` (check a milestone with evidence), `/ws-review` (reviewer + security + privacy in parallel), `/ws-authz` (authorization lint + route review), `/ws-adr <title>`, `/ws-template <role>`. Agents: `@agent-architect`, `@agent-privacy-compliance`, and so on.
Try without installing: `claude --plugin-dir plugin/worksync`.

If you change `.agents/` or `scripts/authz-guard.mjs`, run `node scripts/build-plugin.mjs` to refresh the plugin copy.

## Check the kit (Windows PowerShell or any shell)

```
node scripts/gen-agents.mjs --check
node scripts/build-plugin.mjs --check
node --test scripts/authz-guard.test.mjs scripts/hooks.test.mjs
node scripts/authz-guard.mjs
```
Install the `gitleaks` binary (not an npm package) for secret scanning. If PowerShell blocks `npm.ps1`, use `npm.cmd`.

| Skill | Purpose |

| 🦴 `caveman-optimize` | Analyzes and optimizes your agent config, CLAUDE.md, and skills for minimal token use |
| 🦴 `caveman-review` | Performs code review with tight, compressed feedback — no fluff, only findings |
| 🦴 `caveman-setup` | Sets up Caveman Proxy — a local proxy that shrinks what your agent reads before every provider API call |

| 🏹 `safe-refactor` | Refactors code carefully with verification at each step — no big-bang rewrites |
| 🏹 `surgical-patch` | Makes minimal, targeted fixes to exactly the problem area — no side-effect changes |
